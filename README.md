# Simple Todo CLI

A very small, beginner-friendly Python project that demonstrates:
- basic Python structure (functions, file I/O, lists and dicts),
- saving / loading data (JSON),
- a simple command-line menu,
- Git workflow basics.

## Requirements

- Python 3.7+ installed.

## Files

- `todo.py` — the program. Run with `python todo.py`.
- `tasks.json` — data file created automatically to store tasks.
- `.gitignore` — ignores `tasks.json` so you don’t accidentally commit runtime data.

## How to run

1. Open Git Bash (or any terminal) and navigate to the project folder.
2. If using Windows `cmd`, use `cd` to change directory; in Git Bash, `pwd` shows the path.
3. Run:
   ```bash
   python todo.py
